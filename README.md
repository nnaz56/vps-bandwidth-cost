## 不限流量VPS限的是什么？先算清带宽这本账

答案：限的是端口带宽。所谓不限流量，是流量总数不设上限，但你最多能跑多快，由套餐的端口带宽决定。这笔账很好算，带宽乘以时间就是流量的理论上限：100Mbps 满速一个月约 32TB，50Mbps 约 16TB，20Mbps 约 6.5TB。这就是所有“不限流量”套餐看不见的那条天花板。

反过来算更有用。月流量 1TB，平均下来只需要 3Mbps 出头的持续带宽；考虑突发和晚高峰，再留几倍余量，20Mbps 也绰绰有余。很多人买 1Gbps 大带宽机，一个月实际跑不出 1TB——管道宽不等于水流多。

所以要不要不限流量，取决于一个具体问题：你的流量能不能预估。7×24 挂机下载、跑中转、做采集，流量没数，不限流量才有意义；流量能算清的，按量买大流量套餐更便宜。

还有一点下单前值得确认：VPS 计费的主要方向是出站流量（服务器向外发送的数据），不同商家对入站流量的计算方式不一样，条款里写得有。

## 不限流量和大流量套餐，怎么选

月流量算得清，就买大流量；算不清，才买不限流量。

账例摆出来就明白了。同一家、同一条美国 9929 线路上，原生IP年付款 50Mbps 配 400GB 月流量，年付 ¥299，折合每月约 25 元；不限流量 Lite 是 20Mbps、¥498/月。带宽更高、流量反而少得多，价格差出一个数量级。当然不限流量款还叠了双ISP住宅IP，这个溢价里有一部分是IP钱，但按量卖和包不限的差价摆在这里——流量用得完，按量买就是白赚。

也有例外直接把选择题消掉：QQG.NET 洛杉矶 100Mbps 不限流量年付 $12.99，折合每月一美元出头。这个价格下不用算账，流量焦虑直接清零。

不管买哪种，下单前把这四件事核对一遍：

1. 标题价对应的计费周期：一些商家的低价要一次付 12–24 个月才成立，月付价另算。
2. 备份收费：自动备份普遍按套餐价的 20% 左右另收，不需要就在面板里关掉。
3. 机房附加费：同一家不同机房可能加收位置费，下单页上有写。
4. 退款期：短退款期能把试错成本压到接近零，比如丽萨的 48 小时无条件退款。

## 按使用场景挑线路：电商、建站、下载、流媒体

先挑线路和IP类型，再决定要不要不限流量，流量在不同场景里的权重完全不同。

## 别把不限流量住宅代理当成VPS

两者卖的不是一个东西。VPS 给你一台完整服务器，有 root 权限，能建站、能跑服务；住宅代理只给 IP 和流量通道。按带宽计费的不限流量住宅代理这两年很火：ProxyCC 主打 9000 万 IP 池、195+ 地区，按带宽和并发计费；IPDEEP 的不限量住宅代理也按带宽卖，$85.50 可以用 3 天 100Mbps。这类产品适合爬虫、AI 训练数据采集这种需要海量IP的活；要建站、要 root，还是得回来看 VPS。

## 不限流量VPS常见问题

### 不限流量VPS真的能无限跑吗？

能跑多少取决于端口带宽。100Mbps 满速一个月约 32TB，这是理论上限，谁都绕不过去。至于长时间满速会不会触发商家的管控策略，各家服务条款写法不同，下单前翻一眼比事后扯皮省事。

### 一年十几美元的不限流量VPS靠谱吗？

这个价位当前是真实在售的：QQG.NET 年付 $12.99、ServerHost 年付 $33 都挂在页面上。低价主要来自机房批发带宽的成本和拉新促销。要核对三件事：续费价是否等于促销价、退款政策、线路是否符合用途。核对完，这个价位值得试试。

### 月付还是年付划算？

年付单价明显更低，QQG.NET 年付折合每月约 $1.08。代价是试错成本一次性付掉，所以优先选带短退款期的年付款，或者先月付一个月测线路，再转年付。

### VPS的“不限流量”和代理的“不限流量”是一回事吗？

不是一回事。VPS 的不限流量是服务器的流量上限，代理的不限流量是IP池的用量额度。要 root、要建站、要跑服务，选 VPS；做爬虫和 AI 数据采集这类海量IP的活，选代理。买反了钱就白花了。
